# 八方向待机素材

全部独立帧为 256×256 透明 PNG，原图保持不变。idle.png 是 2048×256 图集，idle.json 为 Phaser JSON Hash 格式；idle-preview.png 仅用于检查。

## 方向约定

方向按屏幕坐标定义，右为 X 正方向，下为 Y 正方向。

| 文件 | 朝向 | 来源 |
| --- | --- | --- |
| idle_s.png | 下、正面 | 原图第 1 人 |
| idle_sw.png | 左下、左前 | 原图第 2 人 |
| idle_w.png | 左 | 原图第 3 人 |
| idle_nw.png | 左上、左后 | 原图第 4 人 |
| idle_n.png | 上、背面 | 原图第 5 人 |
| idle_ne.png | 右上 | 左上镜像 |
| idle_e.png | 右 | 左侧镜像 |
| idle_se.png | 右下 | 左下镜像 |

建议 origin 为 (0.5, 0.96875)，轮廓底部统一落在 y=248。source-map.json 记录源图区域、缩放和镜像来源。镜像会反转衣服纹样及发型的不对称细节；今后可换成独立右侧原画。

## 与行走候选帧的初步匹配

- 左下：walk_candidate 的 chibi_r02 系列，但各帧仍需动作连贯性校准。
- 左侧：chibi_r03 系列包含左前与左侧混合朝向，不能直接全部作为左行走；c07 最接近左侧待机参考，但单帧不足以构成行走循环。
- 左上：chibi_r04 系列为候选，朝向仍有小幅变化。
- 上：chibi_r05 系列为背面行走候选。
- 下：缺少同款 Q 版正面行走序列，不能使用正常比例的 portrait 系列代替。
- 右侧三方向：可以对应左侧候选镜像，仍受原动作连贯性限制。

本批是单帧待机，不是呼吸动画。已检查尺寸、透明背景、图集帧数和静态预览；尚未在 Phaser 中验证待机与行走切换。两批图的服装细节与体型也略有差异，后续切换预览需要继续检查。

## 重新处理

从项目根目录使用 PowerShell 7 运行：

```powershell
pwsh -NoProfile -File tools/process-player-idle.ps1
```

脚本扫描纵向五个人物后裁切，按同一缩放比例输出，不适用于不同排版而未重新检查的原图。
