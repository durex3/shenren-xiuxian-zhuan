# 人物候选帧

原图保留在 raw 中。这里的全部独立人物帧均为 256×256 透明 PNG。

- chibi_r02_c01.png 等：32 张 Q 版候选动作，r/c 表示原图行列，不表示方向。
- portrait_r01_c01.png 等：8 张正常比例人物，与 Q 版分开使用。
- chibi.png / chibi.json：2048×1024 精灵图与 Phaser JSON Hash 图集。
- portrait.png / portrait.json：2048×256 精灵图与对应图集。
- 两张 preview 图片：浅色背景检查图，不用于游戏透明贴图。
- source-map.json：原始裁切区域、画布内偏移和建议锚点。

处理按透明轮廓裁切，同组固定比例缩放，轮廓底部对齐至 y=248，清理少于 100 像素的孤立连通碎片。水平轮廓居中不等于精确角色骨骼对齐；正式动画仍需检查支撑脚和视觉重心。

待八方向待机图到位后匹配朝向。当前图中部分动作朝向不一致，不能直接把每排定义为最终行走动画。当前只检查了静态帧和图集，未完成游戏内动画验证。

重新处理使用 PowerShell 7：pwsh -NoProfile -File tools/process-player-sprites.ps1（从项目根目录运行）。该脚本针对当前原图尺寸与排版，其他图片需重新标定。
