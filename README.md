# 神人修仙传

基于 HTML、JavaScript、Phaser.js 的单机修仙 RPG，同时面向电脑与手机浏览器。

当前阶段：已实现青岚山脚探索原型，支持八方向移动、点击寻路、碰撞、采集、地点交互与本地存档。尚未实现战斗和完整第一章。

## 运行

执行 `npm install` 安装依赖，执行 `npm run dev` 启动，打开终端显示的本地地址。
使用 WASD / 方向键移动，或点击地面寻路；靠近目标后按 E 或点击交互按钮。
手机使用左下方向按钮，右上按钮暂停。`npm test` 运行规则测试，`npm run build` 构建发布文件。
详细模块说明和修改方法见 [山脚探索原型](docs/foothills-prototype.md)。

## 协作规范

每阶段遵循“先讲模块设计思路，再实现带中文注释的代码，最后讲解运行、调用与修改方式”。优先交付可验证的小阶段，避免一次堆入所有长期系统。

最终发布的是静态网页资源。开发时使用本地 HTTP 服务，发布时部署到静态网站服务器；不把双击 HTML 的 file:// 运行方式作为验收要求，因为模块和资源加载依赖 HTTP。
