# 动画效果测试页

在项目根目录运行 `npm run dev`，打开终端显示的地址并追加 `/tests/animation-preview/`，例如 `http://127.0.0.1:5173/tests/animation-preview/`。不要双击 HTML 文件启动。

本页使用 Phaser 单独预览素材，不修改正式游戏和存档，不代表正式战斗逻辑已经完成。它通过 Vite 开发服务器运行，不随当前正式首页构建发布。

- 选择主角或赤玉灵蛛，再选择动作，点击播放。暂停后可逐帧查看，取消循环会停在最后一帧。
- 默认 6 帧/秒，可调整到 1～16 帧/秒；使用“叠加待机参考”检查身体和脚部位置漂移。
- 原图画布等比缩放，保留透明留白；不会逐帧按轮廓重新放大，避免掩盖大小不一致。
- “显示动作特效”控制普通攻击特效；“护盾”可预览主角护盾在两个角色上的保持、受击和破裂效果。
- 镜像用于检查图片自身朝向，同时翻转角色和特效图像；目标位置仍固定在左侧，不模拟换阵营。
- 所有一次性动作统一自动播放“战斗待机 → 动作帧 → 战斗待机”；防御、死亡和逃跑会停在动作结束姿势，解除或离开时再回到待机。蜘蛛普通攻击暂用待机、收拢动作、张开动作、待机四帧演示；防御使用待机及两张防御图。缺少的受击等动作不生成占位图。

修改 `preview.js` 顶部的 `actors` 可改变文件和播放顺序；修改 `effectFiles` 可更换特效。特效触发时机位于 `update` 中，是预览用默认值，正式技能需要单独配置。
