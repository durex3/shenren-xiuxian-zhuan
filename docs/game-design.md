# 游戏设计文档

版本：0.1。本文区分“已确认”与“默认方案”。默认方案由开发协作者补充，可随试玩调整，不代表用户已逐项确认。

## 一、已确认的定位

- 名称：《神人修仙传》。普通凡人踏入修仙世界，逐步历练与逆袭。
- 技术：HTML + JavaScript + Phaser.js；电脑和手机浏览器均支持。
- 首版单机、本地存档。联网仅保留合理的接口边界，不在首版建设服务器。
- 探索和养成参考《鬼谷八荒》的自由探索、修炼成长等机制；角色、地点、事件与任务自行设计。
- 美术由作者后续提供，以已提供的三张参考图确定视觉方向：淡彩水墨大地图、山水建筑场景、国风人物。探索角色小比例偏 Q 版，战斗形象更接近正常比例。

## 二、已确认的核心规则

| 模块 | 规则 |
| --- | --- |
| 角色创建 | 自定义姓名、性别、形象，选择金木水火土之一作为初始灵根 |
| 灵根 | 影响属性倾向、功法效果与元素克制，不禁止跨属性学习；后期可获得双属性或变异灵根 |
| 探索 | 俯视角实时移动，已开放地图自由探索，核心区域随章节解锁 |
| 输入 | 电脑 WASD/方向键与点击移动；手机虚拟摇杆和触摸交互 |
| 遭遇 | 明雷与暗雷结合，接触敌人或在危险区域移动触发战斗 |
| 战斗 | 独立回合制场景，按速度行动；我方和敌方各最多 5 个单位 |
| 队伍 | 主角固定出战；开局单人，获得第一只灵兽后为主角 + 1 只灵兽，后期逐步解锁伙伴或灵兽，最终最多 5 人 |
| 阵位 | 每方 3 前排 + 2 后排，影响受击和技能目标 |
| 指令 | 普通攻击、功法、丹药、法宝、防御、逃跑 |
| 战斗资源 | 普通功法消耗灵力，绝招消耗怒气；攻击与受击可积累怒气 |
| 地图交互 | NPC 对话、采集灵草、宝箱、剧情触发点、传送阵 |
| 成长内容 | 修为、境界、装备法宝、灵根功法、炼丹炼器、灵兽、秘境、任务 |
| 失败 | 返回最近已激活安全点或传送阵，保留经验、修为和已获得物品 |
| 历法 | 探索时缓慢推进；对话、背包、暂停时停止；闭关、炼丹、远行明确耗时；离线停止 |
| 闭关 | 加入随机顿悟，可额外获得修为或功法熟练度 |

## 三、第一章：青岚问道

第一章从引气境初期开始，依次经历中期、后期、圆满，完成秘境与突破任务后达到筑基初期。这样既能体验完整突破，又给第二章保留成长空间。

突破统一要求：修为达标、指定材料齐备、对应任务完成。首章首次筑基采用满足条件后必定成功的默认方案，不引入失败扣材料机制。

| 顺序 | 任务 | 内容与教学 | 奖励或解锁 |
| --- | --- | --- | --- |
| 1 | 初入青岚 | 在山脚驿站学习移动、对话，与引路人许照交谈 | 基础功法、任务追踪 |
| 2 | 山道试炼 | 击败山道上的 2 个敌群，学习速度顺序、防御与丹药 | 修为、灵石 |
| 3 | 灵草之约 | 采集 3 份青露草，交给药师林素 | 恢复丹药、采集与背包教学 |
| 4 | 静室引气 | 使用驿站静室闭关一次，学习修炼收益和历法 | 修为、功法熟练度 |
| 5 | 试炼凭证 | 调查失效阵碑，击败守敌，修复秘境入口 | 秘境准入、传送点 |
| 6 | 秘境首战 | 探索雾溪秘境，击败守脉石傀 | 筑基主材料、宗门入门资格 |
| 7 | 筑基问道 | 修为达标后备齐辅材，向接引人复命并完成突破 | 筑基初期、第一章结算 |

支线“遗失的药篓”提供丹药与基础装备；“灵兽踪迹”引出后续灵兽系统。首领的重击提前一回合预告，鼓励防御，不要求拥有伙伴才能通关。

首章范围：山脚驿站、青岚山道、雾溪秘境三张可探索地图，宗门入口作为通关后的展示与后续章节入口。所有名称和奖励暂为可配置的默认值。

## 四、补充默认方案

### 战斗细节

- 每回合开始按当前速度降序确定行动顺序，同速按稳定单位编号排序；速度变化从下一回合生效。
- 默认在单位轮到行动时选择指令，选择期间不计时。阵位在战斗外调整。
- 普通近战优先选存活前排；前排为空时可攻击后排。穿透、远程和范围技能按各自目标规则处理。

#### 战斗布局与美术视角

- 战场采用左右水平对阵：敌方区域在画面左侧，我方区域在画面右侧；双方单位在同一战斗区域内按前排、后排排列，不采用上下分屏。
- 双方各有 3 个前排位置和 2 个后排位置。推荐的稳定位置 ID 为：`front-left`、`front-center`、`front-right`、`back-left`、`back-right`。
- 第一章获得赤玉灵蛛后，默认推荐赤玉灵蛛位于我方 `front-center`，主角位于我方 `back-center`（逻辑位置可映射到 `back-left` 或 `back-right`），由灵兽承担前排压力，主角在后排施放功法。
- 我方角色默认面向左侧敌方区域，敌方角色默认面向右侧我方区域。攻击特效从角色身体前端朝敌方区域释放。
- 角色采用统一的 Q 版三分之四斜视角，而不是严格水平侧面图。这样可以与现有主角和赤玉灵蛛素材保持一致；“左右水平布局”描述的是战场站位，不要求角色身体轴线完全水平。
- 赤玉灵蛛的头部、眼睛、触肢和蛛丝攻击朝左；敌方版本可在运行时使用水平镜像，使其朝右。镜像只改变视觉朝向，不改变技能数值、碰撞体或阵位 ID。
- 角色待机、攻击、受击和死亡动画必须保持同一三分之四视角、角色比例、脚底基线和朝向，避免动画切换时跳动。
- 战斗画面建议分为上方状态信息区、中间角色与特效区、下方指令区。指令区固定显示普通攻击、功法、丹药、法宝、防御和逃跑；角色和特效不得遮挡指令区。

#### 阵位与目标规则

- 双方都使用 5 个稳定阵位：`front-left`、`front-center`、`front-right`、`back-left`、`back-right`，最多 3 个前排和 2 个后排。
- 普通近战攻击默认只能选择存活前排；当目标方前排全部阵亡后，才允许直接选择后排。
- 远程攻击和单体法术可以选择任意存活单位；穿透技能可以无视前排保护直接指定后排。
- 横排技能命中指定的一排，纵列技能命中同一列的前后排，全体技能命中所有存活单位；范围技能的伤害倍率由技能数据配置。
- 前排主要承担伤害并适合防御、嘲讽、保护类单位；后排适合远程、法术和辅助单位，但更容易受到穿透与范围技能影响。
- 阵位只改变目标筛选和技能效果，不改变单位基础属性；换位在战斗外进行，后续可通过特定技能临时换位。
- 开局主角默认位于 `front-center`；获得灵兽或伙伴时根据单位标签给出推荐阵位，同时允许玩家手动调整。
- 首版手动操作优先，战斗稳定后补自动战斗和 1 倍/2 倍演出速度。倍速不改变伤害、回合数或历法消耗。
- 灵力跨战斗保留，安全点可恢复；怒气每场从零开始，默认上限 100。数值后续调试。
- 首领战禁止逃跑；普通战允许逃跑。逃跑或战败返回探索后短暂免遇敌，防止立刻再次进入战斗。
- 已消耗丹药不因战败返还；未结算战斗不发奖励。保留玩家战前持有和探索中已领取的资源。

### 修炼与时间

- 统一用整数“游戏分钟”记时，初始为修仙历 1 年 1 月 1 日；每月 30 天，每年 12 月。
- 初始探索时间比例：现实 1 秒对应游戏 1 分钟，作为可调参数。
- 闭关可选 1/3/7 天，先显示预计基础收益和耗时，确认后立即结算，不要求现实等待。
- 顿悟初始按闭关每天独立判定，初始概率 5%；额外收益按该日基础修为的 50% 计算，或获得功法熟练度。拆分闭关不会额外增加判定次数。
- 修为达到当前阶段上限后提示突破，避免无提示地浪费长时间闭关。
- 战斗期间暂停连续时间推进，战斗结束统一结算少量时间。浏览器切到后台自动暂停。
- 历法只由游戏行为推进，不依赖现实系统日期。第一版不加入寿尽强制结束存档机制。

### 宗门、存档与界面

- 后续宗门系统支持任务、贡献、兑换、功法和修炼场所。默认允许退出并重新入宗，设贡献清零与入宗条件，具体平衡后续制定。
- 本地存档采用 IndexedDB，支持 3 个角色档位、关键节点自动保存、手动保存与 JSON 导入导出备份。
- 首版在探索安全状态保存，不保存正在播放的战斗中间态。自动存档必须覆盖创建角色、领奖、突破和战斗结算。
- 手机优先横屏布局；竖屏提供清楚的横屏建议。任务追踪可折叠，战斗布局容纳双方各 5 个单位。
- NPC 关系、炼器、复杂灵兽养成和多宗门模拟属于后续阶段，不能阻塞第一章闭环。

## 五、数据约定

任务、敌人、物品、技能、灵根、境界、地图与对话使用稳定 ID。显示名称可修改，存档仍使用 ID 关联。

奖励领取必须只发生一次；采集与宝箱分别记录状态。闭关推进数天后按时间差更新资源与事件，不能逐帧模拟所有经过的时间。

经验与修为首版统一为“修为”，避免同时维护两个作用重复的等级体系。未来需要生活技能经验时再独立增加。
