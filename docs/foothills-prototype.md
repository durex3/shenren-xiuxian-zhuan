# 山脚探索原型

这一阶段是可运行的探索切片，不包含战斗、角色创建和完整第一章。

## 启动

首次执行 `npm install`，之后执行 `npm run dev`，浏览器打开终端显示的地址。
`npm run build` 生成 dist 目录，部署到静态 HTTP 服务即可运行。

## 操作

- WASD 或方向键移动；点击地面使用 A* 寻路，不能穿过建筑。
- 靠近地点或灵草后，点击右下交互按钮，也可以按 E。
- 手机左下方向按钮移动，右侧按钮交互；支持点击地面。
- 右上暂停，Esc 切换暂停；对话期间停止移动。
- 采集三株灵草并发现药庐完成当前探索目标；有三处可发现地点。
- 每五秒保存探索状态，刷新恢复。此原型使用独立 localStorage 键，正式多角色存档仍按架构计划迁移至 IndexedDB。

## 修改方法

`src/config/world.js`：修改地图大小、速度、建筑位置与交互点。
每个物体的 x/y 是底部中心；width 是显示宽度；foot 是地面碰撞宽、高。
树冠不等于碰撞范围，人物可以从树冠后方经过。图片按底部 y 坐标排序。
`src/scenes/WorldScene.js`：加载资源、创建地图、更新角色、处理交互。
`src/systems/navigation.js`：物理碰撞之外，为寻路网格增加安全余量。
`src/services/SaveService.js`：探索存档校验与持久化。

## 美术处理

`tools/process-world-assets.ps1` 裁切当前三张 2048 方形图集，生成14个透明素材。
脚本针对当前图片布局，不适用于任意图集；换图时要修改裁切矩形。
没有重绘美术，也没有删除旧地图或修改下载目录原图。
当前建筑存在少量白边，岩石与建筑透视略有差别，需要后续精修；本版先验证交互比例。
草地采用单一已验证候选纹理，两张变体没有直接混铺。
